## 📖&nbsp; About Me

I'm a Software Engineering student from Indonesia with a growing focus on **backend development**, currently expanding into **full stack engineering**. I care about writing code that is clear, deliberate, and easy for others to reason about — the same way I approach writing.

Beyond programming, I spend time reading and writing, and I'm genuinely curious about **psychology** and **philosophy** — both of which shape how I think about problems, systems, and people. I tend to prefer steady, meaningful work over work that's simply loud.
